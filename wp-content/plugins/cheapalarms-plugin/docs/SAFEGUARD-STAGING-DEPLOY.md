## Your 3 steps

### 1. WordPress (Hostinger)

1. Install WordPress on the Hostinger site (if not already).
2. **Settings → Permalinks → Post name → Save.**
3. Upload plugin folder to:
   ```
   public_html/wp-content/plugins/cheapalarms-plugin/
   ```
   (git pull from `backend-cheapalarms` or SFTP)
4. Upload these two files from your machine:
   ```
   config/secrets.php    ← from local plugin folder (gitignored, has JWT + upload secret)
   config/instance.php   ← generated by sync script (URLs + CORS)
   ```
5. **Plugins → Activate “CheapAlarms Platform Bridge”.**
6. Test: open  
   `https://skyblue-dolphin-986433.hostingersite.com/wp-json/ca/v1/health`
